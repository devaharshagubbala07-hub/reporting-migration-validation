How I would investigate the exceptions.

Start with the population.

A missing row, unexpected period, or duplicate key can change the interpretation before any arithmetic is considered. Resolve those conditions first.

Ask what each number means.

An unchanged percentage can still use a different denominator. Align the report definitions before interpreting a numerical match or mismatch.

Document what remains open.

Keep the old value, new value, rule, and issue together. Re-run the comparison after a correction and retain the explanation for review.

A review aid, with defined boundaries.

The issue counts are constructed, not a measured detection rate. Exact metadata checks cannot inspect undocumented formulas or detect errors shared by both systems. Tolerances are illustrative project rules, not industry standards. Walk through the audit and its limits.
